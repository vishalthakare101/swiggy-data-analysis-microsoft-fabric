# SQL Scripts

This folder contains SQL scripts used during the Swiggy Data Analysis Project in Microsoft Fabric Warehouse.

## Scripts Included

### Schema Creation
Creates the warehouse schema used to store analytical tables.

### Data Validation
Validates row counts and verifies successful data movement from Lakehouse to Warehouse.

### Date Data Type Correction
Corrects the `order_date` column datatype issue by converting string values into a proper DATE datatype.

## Technologies

- Microsoft Fabric Warehouse
- T-SQL
- Data Validation
- Data Quality Checks
